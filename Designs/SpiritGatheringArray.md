# 聚灵阵系统设计文档 —— 《仙器设计师》

> 版本：v0.0.7 设计基线  
> 系统定位：局外养成系统，通过阵盘摆放灵物提升修炼效率；局内仅影响本人灵力回复速度。  

---

## 一、系统概述

### 1.1 设计目标

聚灵阵是玩家在局外构建的灵气汇聚装置，通过合理摆放灵物（灵石、聚灵珠、阵旗、五行材料）来提升阵眼处的灵气浓度，从而：
- **修炼加速**：提升角色修炼经验获取速度。
- **突破加速**：提升角色突破成功率/减少突破所需时间。
- **炼丹供灵**：为炼丹炉提供稳定的灵气来源。
- **法宝温养**：后续开放，用于缓慢提升法宝属性。
- **局内灵力回复**：局内战斗中，角色灵力自然回复速度受聚灵阵加成。

> **关键约束**：聚灵阵的局外增益**不改变关卡难度**。局内仅加速本人灵力回复，不影响敌方属性或关卡设计。

### 1.2 核心概念

| 概念 | 定义 |
|------|------|
| **阵盘** | 承载灵物摆放的网格区域，随玩家境界扩大。 |
| **阵眼** | 阵盘中心格，灵气汇聚的核心点，所有浓度计算以阵眼为原点。 |
| **格位** | 阵盘上的可摆放位置，每个格位可放置一个灵物。 |
| **灵物** | 可摆放在格位上的物品：灵石、聚灵珠、阵旗、五行材料。 |
| **聚灵浓度** | 阵眼处的灵气密度，决定阵法效果强度。 |
| **聚灵值** | 每个灵物的基础灵气产出值，由品质和类型决定。 |
| **距离衰减** | 灵物距离阵眼越远，对阵眼浓度的贡献越低。 |
| **相邻加成** | 相邻格位上的灵物五行相生/相克时，产生额外加成/减成。 |

## 二、阵盘系统

### 2.1 阵盘尺寸与境界对应

阵盘随玩家境界扩大，以阵眼为中心，向四周扩展。

| 境界 | 阵盘半径 | 阵盘尺寸 | 总格位数 |
|------|----------|----------|----------|
| 凡人 | 3 | 7×7 | 49 |
| 练气 | 3 | 7×7 | 49 |
| 筑基 | 4 | 9×9 | 81 |
| 金丹 | 4 | 9×9 | 81 |
| 元婴 | 5 | 11×11 | 121 |
| 化神 | 5 | 11×11 | 121 |
| 炼虚 | 6 | 13×13 | 169 |
| 合体 | 6 | 13×13 | 169 |
| 大乘 | 7 | 15×15 | 225 |
| 渡劫 | 7 | 15×15 | 225 |

> **半径定义**：从阵眼到边缘的距离（格数）。半径 3 = 阵眼 ±3 格 = 7×7 网格。
> 每提升 2 个境界，半径 +1。初始凡人境即开放 7×7 阵盘。

### 2.2 格位类型

| 类型 | 位置 | 功能 |
|------|------|------|
| **阵眼** | 阵盘正中心（坐标 0,0） | 不可放置灵物，为灵气汇聚核心点。显示当前总聚灵浓度。 |
| **普通格位** | 阵眼以外的所有格位 | 可放置任意灵物。 |
| **边界格位** | 阵盘最外圈 | 无特殊功能，仅为可摆放区域。 |

### 2.3 坐标系统

- 阵眼为原点 (0, 0)。
- X 轴向右递增，Y 轴向上递增。
- 曼哈顿距离：`dist = |x| + |y|`（用于距离衰减计算）。
- 欧几里得距离：`dist = sqrt(x² + y²)`（用于视觉效果，不参与计算）。

## 三、灵物系统

### 3.1 灵物类型

| 类型 | 基础聚灵值 | 五行属性 | 特殊效果 |
|------|------------|----------|----------|
| **灵石** | 品质决定 | 无 / 可注入 | 无 |
| **聚灵珠** | 品质×2 | 固定五行 | 同属性相邻时额外 +10% |
| **阵旗** | 品质×1.5 | 固定五行 | 以自身为中心，周围 8 格获得 +5% 聚灵效率 |
| **五行材料** | 品质对应值 | 固定五行 | 参与相邻相生/相克计算 |

### 3.2 灵石品质与聚灵值

灵石是最基础的灵物，按品质分为 9 档：

| 品质 | 名称 | 基础聚灵值 | 颜色 |
|------|------|------------|------|
| 1 | 下品灵石 | +2 | 灰白 |
| 2 | 中品灵石 | +5 | 淡绿 |
| 3 | 上品灵石 | +10 | 青蓝 |
| 4 | 极品灵石 | +18 | 紫金 |
| 5 | 地品灵石 | +30 | 暗金 |
| 6 | 天品灵石 | +50 | 纯白 |
| 7 | 仙品灵石 | +80 | 七彩 |
| 8 | 神品灵石 | +120 | 混沌 |
| 9 | 圣品灵石 | +200 | 虚无 |

### 3.3 五行材料聚灵值（完整版）

五行材料作为聚灵阵的核心摆件，其聚灵值由品质和正负极性共同决定。

| 品质 | 正聚灵值 | 负聚灵值 | 含 0 | 五行属性强度 |
|------|----------|----------|------|--------------|
| 白 | +1 | -1 | 含 0 | 1 |
| 蓝 | +2, +1 | -2, -1 | 含 0 | 2 |
| 紫 | +3, +2 | -3, -2 | 无 ±1 | 3 |
| 金 | +4, +3 | -4, -3 | 无 ±1 | 4 |
| 橙 | +5, +4 | -5, -4 | 无 ±1 | 5 |
| 红 | +6, +5 | -6, -5 | 无 ±1 | 6 |

> **正负聚灵值含义**：
> - **正值材料**：产生正向灵气，适合放置于阵盘大部分区域。
> - **负值材料**：产生"逆灵气"或"煞气"，对阵眼浓度有 subtractive 效果，但可用于特殊炼制加成（如输出/技能部件加成）。
> - **含 0**：该品质材料中存在聚灵值为 0 的变种，纯粹作为占位/过渡使用。

### 3.4 材料五行属性与聚灵值的关系

材料的"五行属性强度"等于其品质值（白=1, 蓝=2, 紫=3, 金=4, 橙=5, 红=6）。

五行属性强度与聚灵值共同决定阵眼灵气的"属性偏向"：
- 阵眼灵气属性 = 所有灵物五行属性的加权平均（按聚灵值绝对值加权）。
- 偏向某一五行时，该属性的修炼/突破获得额外加成（同属性 +10%，相生 +5%）。

## 四、聚灵浓度计算

### 4.1 基础公式

阵眼的**总聚灵浓度**由三个层次叠加计算：

#### 第一层：单体灵物贡献

每个灵物对**阵眼**的基础贡献 = `灵物聚灵值 × 距离衰减系数`

**距离衰减系数**（以阵眼为原点，曼哈顿距离）：

| 曼哈顿距离 | 衰减系数 | 备注 |
|------------|----------|------|
| 0（阵眼本身）| 0 | 阵眼不可放置灵物 |
| 1 | 1.0 | 紧邻阵眼，无衰减 |
| 2 | 0.85 | |
| 3 | 0.70 | |
| 4 | 0.55 | |
| 5 | 0.40 | |
| 6 | 0.30 | |
| 7 | 0.20 | |
| ≥8 | 0.15 | 最低衰减底线 |

> 衰减公式：`factor = max(0.15, 1.0 - (dist - 1) × 0.15)`，其中 dist ≥ 1。

#### 第二层：相邻格位五行加成

对于阵盘上的**每一对相邻格位**（上下左右，不含对角），检查两者的五行属性：

| 关系 | 效果 |
|------|------|
| 相生（A 生 B） | B 的聚灵值 × 1.05，A 不变 |
| 相克（A 克 B） | B 的聚灵值 × 0.95，A 不变 |
| 相同 | 两者聚灵值 × 1.02（共鸣加成） |
| 无关 | 无变化 |

> **相生链**：金 → 水 → 木 → 火 → 土 → 金  
> **相克链**：金克木，木克土，土克水，水克火，火克金

#### 第三层：阵眼总浓度汇总

`总聚灵浓度 = Σ(每个灵物的基础贡献 × 相邻加成后的有效值)`

### 4.2 计算示例

假设阵眼周围一圈（距离 1）摆放了 5 个五行材料：

| 位置 | 材料 | 五行 | 聚灵值 | 基础贡献 |
|------|------|------|--------|----------|
| 上 | 金材料 | 金 | +3 | +3 × 1.0 = +3 |
| 下 | 水材料 | 水 | +2 | +2 × 1.0 = +2 |
| 左 | 木材料 | 木 | +3 | +3 × 1.0 = +3 |
| 右 | 火材料 | 火 | +2 | +2 × 1.0 = +2 |
| 左上 | 土材料 | 土 | +1 | +1 × 1.0 = +1 |

相邻检查（仅检查上下左右相邻关系）：
- 上(金) 与 左(木)：金克木 → 木的聚灵值 ×0.95 = 3×0.95 = 2.85
- 上(金) 与 右(火)：火克金 → 金的聚灵值 ×0.95 = 3×0.95 = 2.85
- 下(水) 与 左(木)：水生木 → 木的聚灵值 ×1.05 = 3×1.05 = 3.15
- 下(水) 与 右(火)：水克火 → 火的聚灵值 ×0.95 = 2×0.95 = 1.9
- 左(木) 与 右(火)：木生火 → 火的聚灵值 ×1.05 = 2×1.05 = 2.1

> 注：实际计算中，每个灵物可能受到多个相邻关系影响，所有相邻加成**乘法叠加**。例如左(木)同时受到上(金)相克和下(水)相生，则木的最终聚灵值 = 3 × 0.95 × 1.05 = 2.9925。

总聚灵浓度 = 2.85 + 2 + 2.9925 + 2.1 + 1 = **10.9425**

## 五、聚灵阵效果映射

### 5.1 聚灵浓度 → 修炼/突破加速

聚灵浓度通过"线性衰减等效值"映射到实际加成。线性衰减等效值的设计目的是让后期高浓度不至于产生爆炸性收益。

**线性衰减等效值公式**：
`等效值 = min(1.0, ln(浓度 + 1) / ln(最大理论浓度 + 1))`

> 其中最大理论浓度为当前境界阵盘全放满红品聚灵珠的理论值（约 500~2000，随阵盘大小变化）。

**效果映射**：

| 效果类型 | 公式 |
|----------|------|
| 修炼速度加成 | `等效值 × 100%`（即等效值 = 1.0 时，修炼速度翻倍） |
| 突破成功率加成 | `等效值 × 20%`（即最多 +20% 突破成功率） |
| 局内灵力回复加成 | `等效值 × 50%`（即最多 +50% 灵力自然回复速度） |
| 炼丹灵气供应 | `浓度 × 0.1` 灵气/分钟，自动存入炼丹炉 |

### 5.2 境界与效果上限

为防止低境界玩家通过大量低级材料堆砌出不合理的高收益，每个境界有**聚灵浓度收益软上限**：

| 境界 | 浓度软上限 | 超过后的衰减 |
|------|------------|--------------|
| 凡人 | 20 | 超过部分 ×0.5 |
| 练气 | 50 | 超过部分 ×0.6 |
| 筑基 | 100 | 超过部分 ×0.7 |
| 金丹 | 200 | 超过部分 ×0.75 |
| 元婴 | 350 | 超过部分 ×0.8 |
| 化神 | 550 | 超过部分 ×0.85 |
| 炼虚 | 800 | 超过部分 ×0.9 |
| 合体 | 1100 | 超过部分 ×0.95 |
| 大乘 | 1500 | 无衰减 |
| 渡劫 | 2000 | 无衰减 |

> 软上限不影响"炼丹灵气供应"的计算，仅影响修炼/突破/回复加成。

### 6.2 交互设计

1. **拖拽摆放**：从右侧灵物背包拖拽灵物到阵盘格位。
2. **点击移除**：点击已摆放的灵物，灵物回到背包。
3. **悬停提示**：悬停在灵物上显示其聚灵值、五行属性、相邻关系预览。
4. **浓度实时更新**：每次摆放/移除灵物后，阵眼浓度与效果预览实时刷新。
5. **最佳摆放提示**（可选）：高亮显示对当前灵物最有利的摆放位置（绿色=相生增益最大，红色=相克损失最小）。

### 6.3 阵盘视觉风格

- 阵盘背景为深色石板纹理，格位之间有微弱的灵气光线分隔。
- 阵眼处有一个缓慢旋转的灵气漩涡，漩涡颜色反映当前灵气属性偏向。
- 灵物摆放后，从灵物到阵眼有微弱的灵气丝线连接，丝线粗细反映贡献度。
- 相邻相生的灵物之间有绿色流光连接；相克的有红色暗流闪烁。
- 阵盘边缘有淡淡的符文边框，随境界提升，符文复杂度增加。

## 七、灵气属性偏向与特殊效果

### 7.1 灵气属性计算

阵眼灵气属性偏向 = 所有灵物五行属性的加权平均：

`属性偏向_五行X = Σ(该灵物聚灵值绝对值 × 五行X权重) / Σ(所有灵物聚灵值绝对值)`

五行权重：
- 灵物五行 = X → 该属性权重 = 1.0
- 灵物五行 = 相生X → 该属性权重 = 0.3
- 灵物五行 = 相克X → 该属性权重 = -0.2
- 无关 → 权重 = 0

**主导属性判定**：
- 若某五行属性偏向 ≥ 40%，则阵眼灵气判定为该属性。
- 若最高属性 < 40%，则判定为"混沌灵气"，无特殊偏向加成，但所有属性获得 +3% 均衡加成。

### 7.2 属性偏向加成

| 阵眼灵气属性 | 修炼加成 | 突破加成 | 特殊效果 |
|--------------|----------|----------|----------|
| 金 | 金属性功法修炼 +15% | 金丹期突破 +10% | 法宝攻击力微幅提升 |
| 木 | 木属性功法修炼 +15% | 木属性瓶颈突破 +10% | 生命恢复速度微幅提升 |
| 水 | 水属性功法修炼 +15% | 悟性突破 +10% | 灵力上限微幅提升 |
| 火 | 火属性功法修炼 +15% | 攻击性突破 +10% | 技能冷却微幅缩短 |
| 土 | 土属性功法修炼 +15% | 防御性突破 +10% | 物理防御微幅提升 |
| 混沌 | 全属性修炼 +8% | 全突破 +5% | 全属性微幅提升 +3% |

> 特殊效果数值较小，定位为"锦上添花"，不改变核心战斗平衡。

## 八、局内生效机制

### 8.1 灵力回复加成

局内战斗中，角色的灵力自然回复速度受聚灵阵加成：

`实际回复速度 = 基础回复速度 × (1 + 聚灵阵等效值 × 0.5)`

- 基础回复速度由角色"气"属性决定（气越高，基础回复越快）。
- 聚灵阵加成最高 +50%（等效值 = 1.0 时）。
- 灵力回复为持续被动效果，无需玩家主动操作。

### 8.2 与修炼系统的数据流

```
聚灵阵摆放 → 实时计算阵眼浓度 → 存储 CultivationArrayValue
                                    ↓
              局外：修炼/突破时读取 → 计算修炼速度/突破成功率加成
              局内：战斗开始时读取 → 计算灵力回复速度加成
```

### 8.3 PlayerProfile 数据注入

在 `PlayerProfile` 类中新增字段：

```csharp
public float CultivationArrayValue { get; set; } // 当前聚灵阵等效值 (0~1)
public float ArrayConcentration { get; set; }    // 当前阵眼聚灵浓度原始值
public ElementType ArrayDominantElement { get; set; } // 阵眼主导五行属性
```

> 此前 `CultivationArrayValue` 为占位 0，本版本完成真实计算注入。

## 九、炼丹炉供灵与灵气结晶

### 9.1 炼丹炉供灵

聚灵阵产生的灵气可自动导入炼丹炉，作为炼丹的燃料/催化剂：

`炼丹炉灵气供应 = 阵眼浓度 × 0.1`（灵气/分钟）

- 灵气自动累积于炼丹炉的"灵池"中。
- 炼丹时消耗灵池中的灵气来替代部分材料需求或提升炼丹成功率。
- 灵池有上限：`灵池上限 = 境界等级 × 1000`。达到上限后不再累积。

### 9.2 灵气结晶

当灵池满且聚灵阵持续运行时，多余的灵气自动凝结为"灵气结晶"：

`结晶产出速率 = max(0, 灵气供应 - 灵池消耗) / 10000`（结晶/小时）

- 灵气结晶是通用货币/材料，可用于：购买灵物、修复法宝、交易等。
- 结晶有品质分级（与灵气纯度相关），纯度高时可作为高级炼丹材料。

## 十、数据持久化

### 10.1 聚灵阵存档结构

```csharp
[Serializable]
public class ArraySaveData
{
    public int ArrayRadius;              // 阵盘当前半径
    public List<SlotSaveData> Slots;    // 已摆放的灵物列表
    public float TotalConcentration;     // 上次计算的总浓度（缓存）
    public float CultivationArrayValue;  // 等效值（缓存）
    public ElementType DominantElement;  // 主导属性（缓存）
    public float AlchemySpiritPool;      // 炼丹灵池当前值
    public float SpiritCrystalCount;   // 灵气结晶数量
}

[Serializable]
public class SlotSaveData
{
    public int X;                       // 格位 X 坐标
    public int Y;                       // 格位 Y 坐标
    public string ItemId;               // 灵物唯一 ID
    public int ItemQuantity;            // 数量（灵石可堆叠）
}
```

### 10.2 计算缓存策略

聚灵阵浓度计算涉及 O(N²) 的相邻关系检查，为优化性能：

1. **增量更新**：仅当灵物摆放/移除/替换时，重新计算受影响的局部区域（距离变化范围 + 相邻关系变化范围）。
2. **完整重算**：切换境界（阵盘扩大）时，执行完整重算。
3. **离线计算**：玩家不在线时，聚灵阵仍按最后状态持续产生灵气结晶（基于离线时间计算）。
